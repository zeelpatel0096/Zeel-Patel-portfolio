# Zeel Patel — Portfolio Website

A responsive student portfolio made for an HTML + Bootstrap + JavaScript assignment.

## Tech
- HTML5
- CSS3
- Bootstrap 5.3
- Bootstrap Icons
- Vanilla JavaScript
- Google Fonts

## Before submitting
Update these placeholders in `index.html`:
1. Exact degree/program + semester under Education.
2. School / Class 10 / Class 12 details.
3. Real skills — remove anything you do not know.
4. Real project names, descriptions and technologies.
5. Real email, GitHub and LinkedIn links.

Do not publish made-up contact information.

## Run locally
Simply open `index.html` in a browser. Internet access is needed for Bootstrap, Bootstrap Icons and Google Fonts CDN assets.

## GitHub Pages
1. Create a GitHub repository, e.g. `zeel-patel-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md`.
3. Go to Settings → Pages.
4. Under Build and deployment, select **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. After GitHub finishes deployment, your site will be available at:
   `https://YOUR_USERNAME.github.io/zeel-patel-portfolio/`

## Verified university facts
The portfolio uses Indus University as the institution and Ahmedabad, Gujarat as the location. Verify your personal academic program before final submission.
